💱 Currency Converter

A simple, user-friendly Currency Converter Web App built with React + Vite.
Convert between different currencies quickly right from your browser — no installation, no hassle. 🌍

🚀 Tech Stack / Tools Used
Technology / Tool	Purpose
React.js	⚛️ Front-end UI & logic for currency conversion
Vite	⚡ Fast development server & build tool (vite.config.js)
JavaScript / HTML / CSS	🧰 Basic structure, styling & client-side logic
Node.js & npm	📦 Dependency management (package.json)
🔄 Features

💱 Convert amounts between various currencies

🌐 Lightweight, browser-based UI — no backend required

⚡ Instant conversion results — fast and responsive

🎯 Easy to use — simple interface for quick conversions

🛠️ Getting Started / Local Setup
✅ Prerequisites

Node.js & npm installed

A modern web browser (Chrome, Firefox, Edge, etc.)

📂 Clone & Setup
git clone https://github.com/Balaraman-dev/Currency_Convertor.git
cd Currency_Convertor
npm install
npm run dev

🌐 Open in Browser

After running the dev server, open your browser at:
👉 http://localhost:5173

(or the URL shown in the console)

You should see the currency converter interface, ready for use.

📄 Description / Purpose

Currency Converter is a lightweight, front-end only application to convert currency amounts from one currency to another. It’s perfect for quick conversions without installing anything, and serves as a nice base if you want to add more sophisticated features (historical rates, multi-currency support, etc.).

Built with modern tools (React + Vite), it’s easy to understand, maintain, and extend.

✨ Why Use / Build On This Project

✅ No backend needed — runs entirely in the browser

✅ Simple and clean UI — user-friendly and accessible

✅ Fast setup & development thanks to React + Vite

✅ Flexible base for further enhancements (e.g. more currencies, exchange-rate APIs, UI improvements)
